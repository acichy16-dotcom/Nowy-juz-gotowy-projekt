# Bezpieczeństwo CichyDex

CichyDex nie wymaga logowania, hasła, danych bankowych ani subskrypcji. Dostęp do aparatu jest używany dopiero po działaniu użytkownika. Zdjęcia kart są analizowane lokalnie.

Zgłoszenia bezpieczeństwa należy kierować przez zakładkę Issues tego repozytorium. Nie publikuj w zgłoszeniu haseł, numerów dokumentów, danych płatniczych ani innych danych prywatnych.
