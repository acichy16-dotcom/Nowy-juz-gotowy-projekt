# CichyDex

Oficjalne publiczne repozytorium aplikacji CichyDex, tworzonej przez Adama Cichockiego i markę Cichy TV – Pokémony i Przygody.

- Strona instalacyjna: https://cichydex-scanner.cichyjpdgl.chatgpt.site/start.html
- Kanał twórcy: https://www.youtube.com/@AdamCichocki-i8l
- Polityka prywatności: https://cichydex-scanner.cichyjpdgl.chatgpt.site/privacy.html
- Bezpieczeństwo: https://cichydex-scanner.cichyjpdgl.chatgpt.site/security.html

## Jak działa

CichyDex jest aplikacją PWA. Nie wymaga konta, hasła ani danych bankowych. Zdjęcia kart są przetwarzane lokalnie w przeglądarce przez OCR. Do katalogu TCGdex mogą być wysyłane jedynie odczytane fragmenty tekstu potrzebne do wyszukania karty, nie zdjęcia.

Kod publicznej wersji beta znajduje się w katalogu `public`. Duże pliki modelu OCR są ładowane w aplikacji lokalnie i nie są kopiowane do tego repozytorium.
